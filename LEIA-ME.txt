PESO E CG — H225M (UH-15 / AH-15B)
=================================

O QUE É
-------
App de peso e balanceamento que roda 100% offline no navegador, no
celular e nos iPads usados como EFB. Nada é enviado para a internet;
tudo fica salvo no próprio aparelho.

ARQUIVOS DESTA PASTA (app/)
--------------------------
  index.html ............ o app
  sw.js ................. faz o cache para funcionar offline
  manifest.webmanifest .. dados de instalação (nome, ícone, cor)
  icon-192.png / icon-512.png / apple-touch-icon.png .. ícones do app
                          (usados só no atalho da tela inicial)

USO RÁPIDO (1 arquivo, sem link)
--------------------------------
Basta abrir o index.html no navegador. Já funciona e já salva os dados.
Para o ícone na tela inicial e o modo tela cheia, use a opção com link
abaixo.

COMPARTILHAR UM LINK E USAR OFFLINE (recomendado p/ EFB)
-------------------------------------------------------
1. Publique a pasta app/ inteira em um endereço https. Opções:
   - Servidor / intranet do esquadrão (basta servir os arquivos estáticos).
   - GitHub Pages: suba a pasta num repositório e ative Pages.
   - Netlify Drop (app.netlify.com/drop): arraste a pasta, recebe um link.
   O link final aponta para .../index.html
2. Envie o link para a tripulação (mensagem, e-mail, MDM dos iPads).
3. Em cada aparelho, ABRA O LINK UMA VEZ COM INTERNET e:
   - iPhone / iPad (Safari): botão Compartilhar -> "Adicionar à Tela de Início".
   - Android (Chrome): menu (3 pontos) -> "Adicionar à tela inicial" / "Instalar app".
4. Pronto. A partir daí abre pelo ícone e funciona SEM REDE.
   Para atualizar: com internet, abra o app uma vez — o novo conteúdo
   é baixado e passa a valer na abertura seguinte.

OBSERVAÇÕES
-----------
- Os dados (missão, trigramas, seções recolhidas) ficam salvos por
  aparelho e por configuração (Básica / Operacional).
- Combustível de translado: o limite do campo de combustível segue a
  quantidade de tanques selecionada (1 tanque = 355 kg, 2 = 710 kg).
  Sem tanque selecionado, o campo fica travado em 0.
- "Gerar PDF (arquivar)" gera um documento de AUDITORIA: identificação
  da ANV, resumo (peso, momento, CG, limite, margem, PAX/POB),
  manifesto completo de tudo que estava a bordo (com o que NÃO foi
  instalado listado por seção), ciência da tripulação e assinaturas.
  Abre a impressão com nome de arquivo padronizado; escolha
  "Salvar como PDF".
- Ao trocar o logo-hu2.png, mantenha o mesmo nome de arquivo.
